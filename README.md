# Country Explorer

Explore every country in the world and test yourself with a flag and capital quiz. Made with HTML, CSS and JavaScript.

![demo](demo/demo.gif)

## Features

**Explore**
- all 250 countries with flag, population, region and capital
- search by name
- filter by region
- sort by name, population or area
- click a country to see more details (languages, currencies, area, etc.)
- click border countries to jump to them
- random country button

**Quiz**
- Guess the Flag and Guess the Capital modes
- 10 questions with score, streak and progress bar
- best score saved in localStorage

## Data

- country info from [mledoze/countries](https://github.com/mledoze/countries)
- population from the [World Bank API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392)
- flags from [flagcdn.com](https://flagcdn.com)

## How to run

Just open `index.html` in the browser.
